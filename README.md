# simple-topdown-shooter

прототип топ-даун шутера на гадоте

состоит из:

сцен:
-игрок
-пуля
-игровое поле

скриптов:
-скрипт игрока (передвижение и стрельба)
-скрипт пули (логика полета и удаления)
-скрипт поля (спавн игрока при начале игры)

связи:
скрипт поля спавнит на самом поле игрока при запуске игры, скрипт игрока спавнит пули при нажатии кнопок
